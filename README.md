众所周知，在各种涩涩 play 里，饮食、饮水、睡眠以及排泄同样是剧情张力和涩涩表现的核心一环。

🔒 场景一：排泄限制与时间监控
给角色戴上能够控制排泄的遥控贞操带/锁扣后，时间该怎么跨轮次稳定监控？角色从一开始的微有尿意，到持续忍耐后的注意力分散、动作变形、理性崩坏……这个生理渐进过程怎么跨越几十轮对话稳定延续，而不是 AI 上一轮还难受，下一轮换个动作就突然“恢复出厂设置”？

🔗 场景二：长时间拘束与生存 Play
当你把角色绑起来进行长达几天几夜的 Play，角色无法自由喝水、进食或前往卫生间。怎样通过量化这些生理极限，让身体状态随着剧情真实积累，最终爆发出那种不可言述的反差与破防效果？

这个系统就是为了解决上述痛点而生——它为角色挂载了一个独立于上下文记忆之外的“生理事实数据库”。

💡 核心功能与技术亮点
动态生理阶段演进（拒绝开关式硬套）
全指标持续跟踪：系统持续跟踪 饮水 / 进食 / 排尿 / 排便 / 睡眠与连续清醒 状态。
阶段梯度：平稳期 ➔ 关注期 ➔ 迫切期 ➔ 应急期

客观事实锚定，把演绎权留给正文模型
只记录事实，不绑架剧情：世界书内容整体编写非常克制，界限明确只提供了生理反应，不替正文模型做价值评价。

低 Token 占用，非同行删档机制
默认自理，重点追踪：角色离场不可观察即清；有遗留影响的角色（如药效未过、绑缚未解）只留最小追踪尾巴，等再次登场时无缝衔接。

卡片式中文状态栏：后台 JSON 隐藏运行，前端自动渲染为可视化、可折叠的中文卡片，支持多角色独立状态切换。

脚本：自动拦截并修复 AI 偶尔写错的 JSON 格式。严重格式错误时自动降级恢复上一轮状态，由于只提供格式准确快照，上下文错误漂移问题不会出现，并根据角色状态自动激活世界书绿灯条目。
