# 角色生理状态引擎 · 角色手册

让角色的身体状态跟得上剧情，而不只停留在上一段描写里。

这是一个面向 **SillyTavern（酒馆）＋酒馆助手** 的角色状态与玩法扩展脚本。通过可视化「角色手册」，查看和管理人物的日常需求、周期、体力与持续影响，也可以按需选择玩法、调整人物状态，让前后剧情更连贯。

## 能做什么

- **查看身体状态**：饮水、进食、排尿、排便、睡眠等日常项目按需开启。
- **管理人物记录**：支持自动建档、扫描角色资料、自定义建档、手动编辑与长期记录。
- **延续角色变化**：可选择周期与孕期、性欲、体力以及持续影响等追踪内容。
- **扩展玩法**：在界面中选择需要的玩法与搭配；部分选项可生成输入草稿，修改后由你发送。
- **选择分析方式**：支持内置模式、外接协作分析和外接独立分析。
- **后台更新**：外接分析期间可以继续写正文，支持立即更新与待更新楼层的区间补算。
- **调整阅读界面**：支持晴白等主题、悬浮或正文下显示，以及桌面小图标入口。

功能可以按需开启，不必一次全开。

## 安装与升级

1. 准备好 SillyTavern，并安装、启用酒馆助手。
2. 点击上方下载链接，保存 `2-角色生理状态引擎-酒馆助手脚本-ver5.68.json`。若浏览器直接显示文本，请将原始文件另存为 JSON，不要保存成网页。
3. 打开酒馆助手的脚本管理／脚本库，导入这个 JSON 文件并启用。
4. 回到聊天，找到「角色手册」，进入设置选择需要的功能。

**从旧版升级时，建议先备份聊天和设置，并停用旧版脚本，避免多个版本同时运行。** 如果曾导入本插件旧版的世界书或双正则，也请停用对应的旧组件；角色卡自身的世界书和其他插件不用动。

本仓库提供的是可直接导入的发布脚本，不需要下载整套仓库，也不需要自行构建。

## 第一次使用

1. 在「设置 → 内容设置」开启想追踪的项目。
2. 在「设置 → 运行模式」选择分析方式。不想另配 API，可以先使用内置模式。
3. 在「人物」页按需扫描或手动建立档案，也可以开启自动建档。
4. 需要玩法扩展时，在「玩法」页选择，再配合自己的输入推进剧情。
5. 正常聊天后，在「状态」页或正文下查看更新。

**使用外接独立分析前，建议先检查正文清理。** 按界面提示确认保留了真正的正文，避免把状态栏、额外说明等一起送去分析。没有明确正文标签时，不要随意填写提取标签。

## 三种运行方式

| 方式 | 适合的用法 |
| --- | --- |
| 内置模式 | 使用酒馆当前模型，同时完成正文与状态记录，不必另配分析 API。 |
| 外接协作分析 | 正文模型提供状态交接，再由外接模型整理更新。 |
| 外接独立分析 | 外接模型根据已完成的正文分析状态，正文模型主要负责续写。 |

两种外接方式都需要配置可用的外接 API。配置或测试 API 本身不会自动切换运行模式；外接分析与模型格式修复可能产生额外调用费用。

## 后台更新与常用设置

相关入口在「设置 → 运行模式」。

- **后台分析**：分析时可以继续续写；新产生的楼层会接续处理，状态显示可能稍晚于剧情。
- **立即更新**：以点击时已完成的楼层为截止点，处理待更新内容。
- **指定区间补算**：填写起止楼号，分批处理待更新内容；中途失败后可继续重试。不是覆盖任意历史记录的工具。

后台分析默认开启，更新频率默认每楼。已经完成 5.67 默认调整的聊天，升级到 5.68 会保留你后续的选择。需要同步等待更新时，可关闭后台分析；单独开启的前置推演仍需等待。

## 遇到问题时

- **状态没有更新**：先看状态栏的错误提示，再点「查看返回」。不要仅凭正文写出了某个变化，就认定状态一定已保存。
- **外接格式报错**：部分问题会自动纠正；仍然失败时会保留已有有效记录，可检查返回后重试。
- **人物扫描失败**：可查看扫描返回，或尝试人物页的「兼容扫描」。它适用于部分接口参数不兼容的情况，不保证解决所有连接或模型问题。
- **正文清理确认按钮不可用**：检查标为「需调整」的项目，确认清理后仍保留有效正文，不要直接把内容清空。
- **界面重复或行为异常**：确认只启用了一份本插件脚本，没有同时运行旧版。

反馈时请附上插件版本、运行模式、模型／接口类型、操作步骤、错误截图，以及失败那一次的返回内容。**发到公开 Issue 前，请删除 API Key、私人地址、真实个人信息和不希望公开的聊天内容。**
