# 角色生理状态引擎 · SillyTavern Life State

让角色的身体状态跟得上剧情，而不只停留在上一段描写里。

面向 SillyTavern 的角色状态与玩法扩展工具。通过可视化「角色手册」，查看和管理人物的日常需求、周期、体力与持续影响，支持内置、外接协作和外接独立分析。

**当前版本：5.70**

[下载正式版](https://github.com/koofer-zia/sillytavern-life-state/releases/tag/v5.70) · [反馈问题](https://github.com/koofer-zia/sillytavern-life-state/issues)

## 选择一种安装方式

### 酒馆助手版

需要先安装并启用酒馆助手。在发布页 Assets 下载 `sillytavern-life-state-v5.70.json`，通过酒馆助手的脚本管理导入并启用。只需这一份 JSON，不需要另导入世界书。

### 原生扩展版

不需要酒馆助手；以 SillyTavern 1.18.0 为适配基线。

在酒馆的扩展管理器中选择安装扩展，填写仓库地址：

```text
https://github.com/koofer-zia/sillytavern-life-state
```

也可在发布页下载 `sillytavern-life-state-v5.70.zip`，解压后把整个 `sillytavern-life-state` 文件夹放入酒馆第三方扩展目录，刷新后启用。

**两种方式二选一。升级或切换前备份聊天与设置，停用另一份插件并刷新，不要双开。** 原生版沿用已有聊天记录和设置，不需要重新建档。旧版助手脚本没有互斥能力，务必先停用。

## 第一次使用

1. 在「设置 → 内容设置」开启需要的追踪项目。
2. 在「设置 → 运行模式」选择分析方式；内置模式无需另配分析 API。
3. 在「人物」页扫描或手动建立档案，也可以开启自动建档。
4. 在「玩法」页选择搭配；生成的聊天草稿可修改，由你发送。
5. 正常聊天后，在「状态」页或正文下查看更新。

外接协作和独立分析需要配置外接 API。独立分析启用前按提示检查正文清理；不要在没有对应标签时随意设置“仅保留标签内正文”。分析和格式修复可能产生额外调用费用。

## 5.70 更新

- 新增原生扩展安装方式，可通过 Git 安装和更新，无需酒馆助手。
- 身体改造改为按部位、分支选择完整搭配正文；复杂过程和后续变化可通过聊天引导。
- 新搭配记录分为基础与当前搭配说明；旧 Effect 继续保留、更新和结束，不自动迁移旧搭配，旧身体改造正文不再注入。标记章节保持原样。
- 新增悬浮图标小、标准、大三档，默认尺寸不变，自动记住选择。
- 修复外接周期说明的接续，减少已有模型说明被内置说明覆盖的情况。

身体搭配的记录说明变化后，完整预设参考会先暂停，当前事实继续传递；若只是措辞变化、搭配仍一致，可在「当前搭配 → 核对原预设」确认恢复。已有记录不会因此删除。

## 更新、停用与反馈

Git 安装可用酒馆扩展管理器更新，完成后刷新。手动安装先停用并刷新，再替换整个扩展文件夹，最后启用并刷新；不要混用旧运行文件。助手版导入新版后只启用一份。

停用或删除原生扩展不会清空聊天记录。提示另一份正在运行时，先停用重复安装；提示停止或清理失败时，等待收尾或刷新后再启用。

状态未更新时先看错误提示及「查看返回」。反馈请附版本、运行模式、操作步骤和失败返回；公开前删除 API Key、私人地址及不希望公开的聊天内容。
