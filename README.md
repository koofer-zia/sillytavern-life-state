# 角色生理状态引擎 · SillyTavern Life State

让角色的身体状态跟得上剧情，而不只停留在上一段描写里。

面向 SillyTavern 的角色状态与玩法扩展工具。通过可视化「角色手册」，查看和管理人物的日常需求、周期、体力与持续影响，支持内置、外接协作和外接独立分析。

**当前版本：5.70**

[下载正式版](https://github.com/koofer-zia/sillytavern-life-state/releases/tag/v5.70) · [反馈问题](https://github.com/koofer-zia/sillytavern-life-state/issues)

## 能做什么

- **查看身体状态**：饮水、进食、排尿、排便、睡眠等日常项目按需开启，随剧情时间更新。
- **管理人物档案**：支持扫描角色资料、自定义建档、自动建档、手动编辑与长期记录。
- **延续角色变化**：可选择周期与孕期、性欲、体力及持续影响等追踪内容，让状态衔接后续剧情。
- **扩展玩法**：在界面里选择需要的玩法和搭配，配合自己的聊天输入推进；部分选项可填入草稿，修改后由你发送。
- **选择分析方式**：可使用酒馆当前模型，也可让外接模型负责状态分析。
- **边聊边更新**：外接分析支持后台处理、立即更新和指定区间补算。
- **调整显示**：支持多种主题、悬浮或正文下显示，以及可调大小的小图标入口。

功能可以按需开启，不必一次全开，也不必使用玩法扩展才能追踪日常状态。

## 选择一种安装方式

### 酒馆助手版

需要先安装并启用酒馆助手。在发布页 Assets 下载 `sillytavern-life-state-v5.70.json`，通过酒馆助手的脚本管理导入并启用。只需这一份 JSON，不需要另导入世界书。

### 原生扩展版

不需要酒馆助手；以 SillyTavern 1.18.0 为适配基线。

在酒馆的扩展管理器中选择安装扩展，填写仓库地址：

```text
https://github.com/koofer-zia/sillytavern-life-state
```

也可在发布页下载 `sillytavern-life-state-v5.70.zip`，解压后把整个 `sillytavern-life-state` 文件夹放入酒馆第三方扩展目录，刷新后启用。

**两种方式二选一。升级或切换前备份聊天与设置，停用另一份插件并刷新，不要双开。** 原生版沿用已有聊天记录和设置，不需要重新建档。旧版助手脚本没有互斥能力，务必先停用。

## 第一次使用

1. 在「设置 → 内容设置」开启需要的追踪项目。
2. 在「设置 → 运行模式」选择分析方式；内置模式无需另配分析 API。
3. 在「人物」页扫描或手动建立档案，也可以开启自动建档。
4. 在「玩法」页选择搭配；生成的聊天草稿可修改，由你发送。
5. 正常聊天后，在「状态」页或正文下查看更新。

四个页面各有分工：**状态**看当前结果，**人物**管理档案，**玩法**选择搭配，**设置**调整追踪内容、分析方式和外观。

## 三种运行方式

在「设置 → 运行模式」选择；安装方式不影响这三种模式的使用。

| 方式 | 怎么使用 |
| --- | --- |
| 内置模式 | 使用酒馆当前模型，同时完成正文与状态记录，不必另配分析 API。 |
| 外接协作分析 | 正文模型提供状态交接，再由外接模型整理更新。 |
| 外接独立分析 | 外接模型根据已完成的正文分析状态，正文模型主要负责续写。 |

不想额外配置时，可以先用内置模式。两种外接方式需要在「设置 → 外接 API」配置连接；保存或测试连接不会自动切换模式，分析与模型格式修复可能产生额外调用费用。

独立分析启用前，按提示检查正文清理的预览，确认保留了真正的正文。没有明确正文标签时，不要随意设置“仅保留标签内正文”。

## 常用操作

- **调整人物状态**：在「人物」页选择角色并编辑档案；后续状态仍会随剧情变化。持续影响可在对应人物的状态区域查看、编辑或结束。
- **选择玩法**：在「玩法」页选择人物与搭配，按界面提示应用。聊天草稿不会自动发送，具体过程和后续变化可以直接在聊天里引导。
- **后台分析**：在「设置 → 运行模式」调整更新频率。开启后台分析后可继续续写，状态显示可能稍晚于剧情；需要同步等待时可关闭。
- **立即更新／区间补算**：立即更新处理点击时已经完成的待更新楼层；区间补算填写起止楼号，分批处理未更新内容，失败后可重试接续。
- **调整外观**：在「设置 → 界面外观」切换主题、显示位置、桌面横条或小图标。图标大小只影响收起的按钮，不改变展开面板。
- **沿用常用设置**：在「设置 → 内容设置」点击“保存为新聊天默认”，以后新聊天沿用所选开关，不复制人物档案或玩法搭配。

身体搭配说明变化后，若提示参考暂停，可在「当前搭配 → 核对原预设」检查；只有当前搭配仍一致时才确认恢复，已有记录不会因此删除。

## 更新、停用与反馈

Git 安装可用酒馆扩展管理器更新，完成后刷新。手动安装先停用并刷新，再替换整个扩展文件夹，最后启用并刷新；不要混用旧运行文件。助手版导入新版后只启用一份。

停用或删除原生扩展不会清空聊天记录。提示另一份正在运行时，先停用重复安装；提示停止或清理失败时，等待收尾或刷新后再启用。

## 遇到问题时

- **状态没有更新**：先看状态栏提示，再点「查看返回」检查失败那一轮的结果；报错时会保留已有有效记录。
- **人物扫描失败**：查看扫描返回；遇到接口参数报错时，可尝试人物页的「兼容扫描」。
- **正文清理无法确认**：检查标为“需调整”的项目，确认预览中的正文没有被清空。
- **界面重复或行为异常**：检查是否同时启用了助手版、原生版或旧脚本，只保留一份运行。

反馈请附版本、运行模式、模型／接口类型、操作步骤和失败返回；公开前删除 API Key、私人地址及不希望公开的聊天内容。
